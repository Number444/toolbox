## P0 — 崩溃/数据丢失级

- [ ] **P1-13 卸载轮询异常逃逸（原 P0-1，二次验证后降级）**
  `Toolbox.Plugins/SoftwareUninstallTool.cs:500-548` `async void OnSoftwareDoubleClick` 仅 catch OperationCanceledException；轮询期间 `SoftwareUninstallService.cs:240-284` 读注册表无保护，注册表键被并发程序删改时抛 IOException 从 async void 逃逸。**不崩溃**（App.xaml.cs:31 全局 DispatcherUnhandledException 且 e.Handled=true 兜住），实际后果：弹"异常捕获"对话框 + 卸载轮询静默死亡（`_pendingUninstall` 永久残留、成功提示永不显示）。应用退出期 `Dispatcher.InvokeAsync` 的 TaskCanceledException 同理。
- [ ] **P2-17 悬浮窗首次 Save 静默失败（原 P0-2 改写，二次验证推翻毒化前提）**
  `Toolbox.Plugins/Services/AudioflowSettings.cs:176-189` Save() 无条件写入位置 NaN，而 .NET 9 的 System.Text.Json（Strict 模式）序列化 NaN 直接抛 ArgumentException → 被 `Toolbox.Core/Services/JsonSettingsFile.cs:47-52` catch 吞掉 → 主文件与 .bak 均不写入。**无毒化、无重置**（验证：STJ 序列化先于文件 IO 抛错）。残余影响：未拖过悬浮窗时切换设置，该次变更不持久化，直到拖窗初始化位置后恢复；`:163-173` 的 double.IsNaN 防护是死代码。

## P1 — 明显缺陷

- [ ] **P1-1 Show/Hide 循环泄漏窗口实例（每个隐藏窗口带活 HWND 永不回收）**
  `Toolbox.Plugins/Tools/Services/MusicFloatWindowManager.cs:90,112,130-131,145`。WPF HWND 被 OS 强引用无法 GC；面板每开关一次泄漏一个隐藏窗口，会话内存/GDI 句柄持续增长。对照 ToggleBlur/SetSizeMode 替换路径（:194/:243）正确 Close 旧窗口，唯 Show/Hide 漏。
- [ ] **P1-2 EngineDownloader 先删旧引擎再下载，失败即丢失可用引擎**
  `Toolbox.Plugins/Helpers/EngineDownloader.cs:49-54` 第一步 Directory.Delete(engineDir, true)；`:36` HttpClient 10 分钟整体超时（慢网络易超时）；`:112-116` 无哈希/签名校验。网络中断 → 旧引擎已删、新引擎不完整。
- [ ] **P1-3 OCR 引擎下载"取消"是假取消**
  `Toolbox.Plugins/OcrTool.cs:553` 传 CancellationToken.None；`DownloadDialog.cs:195-200` CancelAndClose 只置标记+关窗。取消后后台继续下载占带宽，完成才检查 Cancelled。
- [ ] **P1-4 PaddleOCR 引擎无释放路径 + SetDllDirectory 进程级污染**
  `Toolbox.Plugins/Helpers/PaddleOcrWrapper.cs:178-186` Dispose() 全库无调用点（工具单例存活整个进程，数百 MB 原生模型常驻无卸载路径）；`:82` SetDllDirectory(enginePath) 永不恢复，此后进程内所有原生 DLL 解析先搜引擎目录。
- [ ] **P1-5 软件卸载列表刷新无互斥/版本号，慢加载覆盖快加载**
  `Toolbox.Plugins/SoftwareUninstallTool.cs:91,458-496,563-572`。快速点两次刷新 → 先启动的慢加载后完成覆盖新数据；卸载轮询期间刷新 → 列表换新实例，轮询结束 Remove 按引用移除失败 → 已卸载软件残留显示。
- [ ] **P1-6 定时关机自定义分钟数无上限，int 溢出为负**
  `Toolbox.Plugins/ShutdownTool.cs:133-135` int.TryParse 任意正整数 + `minutes * 60` 未 checked；输入 ≥ 35,791,395 分钟 → seconds 为负 → `shutdown /s /t 负数` 行为未定义（可能立即关机）。
- [ ] **P1-7 JunkCleaner 取消后重新扫描复用同一可取消 token，状态与数据脱节**
  `Toolbox.Plugins/JunkCleanerTool.cs:572-577`。清理中取消 → 部分已删、尺寸停留旧值；再点"清理已选"基于过期 FileCount/SizeBytes 决策，状态提示与实际不符。
- [ ] **P1-9 架构：插件程序集借用主程序命名空间（依赖方向被破坏）**
  `Toolbox.Plugins/Services/AudioflowSettings.cs:1`、`SoftwareUninstallService.cs:1` 声明 `namespace Toolbox.Services`；`Helpers/EngineDownloader.cs` 等声明 `namespace Toolbox.Helpers`——与主程序 `Services/ToolRegistry.cs:4`、`Helpers/Win32Helper.cs:3` 同名。跨程序集同命名空间并存，插件 OcrTool.cs:8 的 `using Toolbox.Helpers` 解析到插件自身。
- [ ] **P1-10 架构：主程序编译期静态绑定插件类型，依赖倒挂，"反射热加载"对悬浮窗子系统不成立**
  `MainWindow.xaml.cs:694,698,79,552,73-74` 直接绑定 `Toolbox.Tools.Helpers.DwmHelper`、`MusicFloatWindowManager`、`FloatSizeMode`；Core 无 DWM 抽象。插件 DLL 不可缺失，与 ARCHITECTURE.md:187 表述矛盾。
- [ ] **P1-11 架构：ToolRegistry 三策略加载只剩策略 1 可达**
  `Services/ToolRegistry.cs:21-23,65-117`。策略 2/3 因主程序 ProjectReference + 静态绑定必然不可达（插件 DLL 必在主输出目录且登记 deps.json）；一旦触发策略 2/3 的场景出现，主程序自身也无法运行。setup/publish/ 仅 Toolbox.exe + pdb 佐证。
- [ ] **P1-12 架构：同一 Win32 API 在 3 个程序集、9 个文件重复 P/Invoke**
  DwmSetWindowAttribute（Win32Helper.cs:26 vs DwmHelper.cs:62）、DwmExtendFrameIntoClientArea（:85 vs :65）、MARGINS（:90 vs :82）、SetWindowPos（DwmHelper.cs:78 vs ClickThroughHelper.cs:109）、GetCursorPos（SystemTrayHelper.cs:68 vs MainWindow.xaml.cs:676）等；Core 层 P/Invoke 为 0。无统一封装。

## P2 — 潜在风险/收尾

- [ ] **P2-1 回收站类别硬编码 C:\$Recycle.Bin + FileCount>0 门槛，清空范围与扫描范围不一致**
  `Toolbox.Plugins/JunkCleanerTool.cs:68,499,735-744`。系统盘非 C 或权限不足 → 扫描为 0 → 勾选回收站也无法触发清空（静默失效）；触发则清空全部驱动器而扫描只算 C 盘。
- [ ] **P2-2 EngineDownloader 进度映射公式错误，45-80 区间实际只走到 62**
  `EngineDownloader.cs:196` `baseMin + pct*(baseMax-baseMin)/200`（应除 100）；`:202` 解压同样；`:98` 直接跳 100。纯视觉。
- [ ] **P2-3 解压无 zip-slip 防护**
  `EngineDownloader.cs:212-225` zip 条目 FullName 直接拼 Path.Combine，含 `../` 条目可写出目录。来源为固定版本 NuGet 包，风险面小。
- [ ] **P2-4 密码明文落盘 passwords.json**
  `Toolbox.Plugins/PasswordGeneratorTool.cs:26-28,344-357`。明文 JSON 含名字→密码映射，任何读 LocalAppData 的程序可取；UI 已有明文警告（已知权衡）。
- [ ] **P2-5 网卡枚举无异常保护，热插拔竞态可从 CreateContent 冒泡**
  `Toolbox.Plugins/NetworkInfoTool.cs:122-161` GetIPProperties()/GetPhysicalAddress() 无 try/catch；LoadAll 在 CreateContent（:61）直接调用。拔网线/USB 网卡瞬间可能 NetworkInformationException 逃逸。
- [ ] **P2-6 软件去重比较器不一致，大小写不同的重复条目新版被丢弃**
  `Toolbox.Plugins/Services/SoftwareUninstallService.cs:89-103` seenNames 用 OrdinalIgnoreCase 而 list.Find 用大小写敏感 → WOW6432Node 与 64 位视图同软件大小写不同时新条目（可能带版本号）被丢弃。
- [ ] **P2-7 同一软件可被重复双击启动多个卸载进程**
  `SoftwareUninstallTool.cs:513` `_pendingUninstall` 只记录不拦截，轮询期间再双击 → 第二个 UAC + 第二个卸载进程。
- [ ] **P2-8 OCR 高精度失败回退改全局开关，并发识别互相干扰**
  `Toolbox.Plugins/OcrTool.cs:480-488` 回退路径置 `_useHighPrecision=false`；连拖两张图并发识别时第一个失败会降级第二个。
- [ ] **P2-9 引擎目录被 Assembly.LoadFrom 锁定后，重下载的 Directory.Delete 必失败且无法自愈**
  `PaddleOcrWrapper.cs:84` + `EngineDownloader.cs:49-54`。LoadFrom 抛异常后 DLL 已被锁 → 点下载 → 删除失败 → 需重启应用恢复。
- [ ] **P2-10 下载的 nupkg 临时 zip 落 %TEMP% 无权限收紧，解压文件无内容校验**
  `EngineDownloader.cs:118-136,154`。低风险加固项。
- [ ] **P2-12 ToggleBlur/SetSizeMode 失败回滚路径泄漏半成品新窗口**
  `MusicFloatWindowManager.cs:175-187,224-236`。newWindow.Show() 抛异常后回滚只重挂旧窗口，newWindow 未 Close。极端低概率。
- [ ] **P1-14 ResetPosition 在 Docked 状态下留下"内容不可见 + 触发条悬空"死态（二次验证后升级）**
  `MusicFloatWindowManager.cs:434-443` 直接移动 Left/Top，无 State 检查、不调 ForceRestore/DetachFromDock；State 仍 Docked、内容 Opacity=0 且 IsHitTestVisible=false（StartDock :397 / ApplySavedState :347 → :497-498）。**可达**：面板按钮（NeteaseMusicTool.cs:133）与悬浮窗右键菜单（MusicContentControl.xaml.cs:737）均为入口，复位后窗口停在 wa.Left+20 只余触发条。
- [ ] **P2-14 SMTCListener 并发小噪音**
  `SMTCListener.cs:397,167,284-288,88`。`_session!` 在 Stop 置空竞态下可能 NRE（被 catch 吞）；StartAsync 重试与 OnSessionsChanged 可能短暂重复订阅。均被 SemaphoreSlim/事件去重兜住，无实际危害。
- [ ] **P2-15 卸载轮询阶段注册表键被删/应用退出期无兜底（P0-1 同源的分支确认项）**
  `SoftwareUninstallService.cs:240-284` 读注册表无 try/catch。
- [ ] **P2-16 MusicFloatWindow.xaml/.cs 是仅供测试实例化的废弃死代码，未标记废弃**
  `Toolbox.Plugins/Tools/Views/MusicFloatWindow.xaml.cs`（819 行）。生产只创建 Acrylic/Transparent（MusicFloatWindowManager.cs:325-326）；仅 NeteaseMusicToolTests.cs:152 实例化；其单例与 ForceResetInstance（:151,159,173）只为测试服务；margin 常量 (4,10,0,0) 已与新控件 (5,10,5,0) 分叉。注：移动/删除前须先改测试。
