## 1. 新增：RemoteControlTool 局域网远程控制（68febd8 起）

浏览器远程控制系统操作与状态查看的新工具，分类归入「🌐 网络与开发」。

### 核心能力
- **TcpListener 手写 HTTP 服务**（零第三方依赖，普通权限可监听）；备方案 HttpListenerServer 一并实现，实机冒烟不通过可切换
- **Web 控制页**（内嵌单 HTML，深色主题对齐 Toolbox 色板）：快捷操作（锁屏/睡眠/关显示器/重启资源管理器）、电源控制（2x3 快捷网格 + 自定义分钟）、系统状态（CPU/内存/磁盘/电池/运行时长/公网 IP，1.2s 刷新）、操作日志、已连接设备管理
- **认证与会话**：密钥认证（定长比较防时序侧信道、按 IP 隔离 5 次失败锁 30s）、8h 会话（HttpOnly Cookie）、**免登录模式**（密钥留空启动，控制页不弹登录界面）
- **服务常驻**：切换工具/托盘后台不中断，仅手动停止或关闭 Toolbox 终止
- **设备管理**：认证成功记录设备（remote-control.json），已记录设备访问自动填密钥，面板/控制页双端查看与踢出
- **审计**：指令/时间/来源 IP，最近 20 条
- **安全防线**：CSRF 自定义头 + 危险指令服务端 confirm 强校验 + Host 白名单（防 DNS rebinding）+ 并发连接上限 64 + 请求限长（16KB/1MB）+ 单请求超时

### 产品迭代（同日多轮）
- 密钥文案替换 Token；输入框常驻深色提示；地址逐行可复制；当前密钥/访问地址 2px 分隔线
- 电池信息（公共类 GetBatteryInfo，首页时钟卡片 + 控制页共用；无电池显示 100% 浅灰占位）
- 公网 IP 显示（公共方法优先 + 私有兜底 + 30s 单缓存）
- 断连自绘弹窗（连续第 4 次无响应 ≈6-8s 判定；尝试重新连接 = 刷新页面）
- 控制页"关闭 Toolbox"红色按钮（自绘确认 → 正常关闭清理路径）
- 设置页新增远程控制卡片（自动启动开关 + 默认端口 + 默认密钥，Core AppSettings 授权扩展）
- 设置合并为单一 json（remote-control.json：密钥/端口/开关 + 设备表）

### 全链路审查修复（160/160 测试全绿）
- 密钥注入改 JSON 字面量转义（特殊字符密钥不再破坏控制页）
- 免登录模式会话惰性清理补全；设置 Save 锁内快照防并发丢失
- status/network 只读指令锁外执行（不阻塞关机指令）；电池 0xFF 独立判定；空串密钥规范化
