# EdgeGlowLayer 光晕系统人工回归清单

> 用途:EdgeGlowLayer(鼠标光晕 + 控件边缘照亮)是全项目回归率最高的模块,历史上多次「修新问题复活旧问题」。
> **任何涉及以下文件的改动,交付前必须对照本清单实测一遍**:
> - `Toolbox.Core/Helpers/EdgeGlowLayer.cs` 本体
> - `Toolbox.Core/Helpers/GlowCardMarker.cs`(卡片 opt-in 标记)
> - 各窗口/工具页中 hover 跟踪、ScrollViewer、裁剪相关的调用方
>
> 测试前确认:设置页中「鼠标光晕」「控件光晕」两个开关均打开。

## 1. 遮挡透出(最高危,回归过 2 次)

- [ ] C 盘清理工具页:窗口高度调小到内容被主界面裁剪,鼠标移到**被盖住的复选框所在位置上方**,被遮区域不得透出光晕(含底部和两侧)
- [ ] 定时关机/密码生成器等长页面:滚动到底部卡片被裁掉一半的状态,被裁部分不得有任何亮边
- [ ] 鼠标在被遮挡控件正上方移动时,照亮效果应作用于**实际可见的上层元素**,不得穿到下层

## 2. 滚动一致性

- [ ] 控件被照亮时滚动页面:光晕必须跟随控件移动,不得停留在原地
- [ ] 长卡片一半滚出视口:视口内部分照亮正常,视口外不得出现「假亮边」横线(PushClip 裁剪生效)
- [ ] 快速来回滚动:无残影、无错位、无闪烁

## 3. Hover 边界行为

- [ ] 鼠标从远处逐渐接近控件:光晕应逐渐增强(被鼠标「照亮」),不得在快要接近时突然熄灭
- [ ] 鼠标悬停在控件上:亮边只显示**朝向鼠标一侧**的弧度(径向渐变,背光侧熄灭),亮度足够
- [ ] 鼠标移出控件:光晕瞬时熄灭(0ms),无渐隐尾迹
- [ ] 控件圆角与光晕圆角逐像素贴合:按钮、胶囊开关、复选框、下拉框逐个检查,无缝隙/溢出/缩进

## 4. 下拉框(ComboBox)

- [ ] 下拉框四周光晕像素级贴合圆角
- [ ] 点击展开弹层:弹层内容块四角不得从圆角后方突出尖角
- [ ] 弹层展开状态滚动/切换页面:弹层关闭,无残留光效

## 5. 界面/工具切换状态隔离

- [ ] 照亮某控件后立即切换到另一个工具页:原页面所有光效立即销毁,新页面 0ms 残留
- [ ] 主窗口 ↔ 悬浮窗交替操作:两边光效互不泄漏

## 6. 双窗口与显示模式

- [ ] 主窗口:各工具页(至少抽 C 盘清理、定时关机、密码生成器、设置)照亮正常
- [ ] 音乐悬浮窗大模式:卡片(已 opt-in)照亮正常,封面控件区无异常光效
- [ ] 音乐悬浮窗紧凑模式:同上
- [ ] 顶栏四个按钮:仅底部两圆角有光效,顶部圆角不超出窗口上边缘
- [ ] 鼠标移到顶栏非按钮区域:鼠标光晕正常显示(历史 bug:顶栏区域光晕消失)

## 7. 崩溃防护(历史事故)

- [ ] 窗口启动/关闭/最小化过程中快速移动鼠标:不得抛出 `PointFromScreen 此Visual未连接到PresentationSource` 异常
- [ ] 打开软件立即晃动鼠标:不报错(历史事故:启动时 InitHalo 崩溃)

## 8. 开关与持久化

- [ ] 设置页关闭「控件光晕」:所有边缘照亮立即消失;重开恢复
- [ ] 设置页关闭「鼠标光晕」:鼠标光晕消失,控件照亮不受影响
- [ ] 重启软件:两个开关状态保持

## 9. 非交互元素绝对禁区

- [ ] TextBlock、Label、分割线、背景层、普通 Border/Grid/StackPanel:任何情况下不得出现光晕
- [ ] 未标记 `GlowCardMarker.IsGlowCard` 的卡片容器:不得发光

## 10. 动画同步(2026-08-11 新增,改动动画/光晕同步逻辑必测)

- [ ] 设置层进入/退出动画期间**光标静止**:光圈跟随动画移动/缩放,不得定格在动画起点
- [ ] 工具切换两段式动画期间光标静止:光圈跟随,内容区无残留旧位置光晕
- [ ] 切回前台动画(最小化→还原)期间光标静止:光圈跟随左侧滑入/右侧上滑
- [ ] **动画结束后(过 1~2 秒)**:光晕不再逐帧刷新——任务管理器观察 Toolbox 进程 CPU 回落(动画期间短暂上升正常);若有持续高占用 = 闸门未关(HoldEnd 清时钟缺失,见 07-ui-system「重绘触发与动画同步」)
