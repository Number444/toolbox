JunkCleanerTool 审计问题清单
================================


== P0 严重问题 ==

1. 缩略图缓存删除范围过宽 (第87行)
   路径: %LocalAppData%\Microsoft\Windows\Explorer
   现状: 删除该目录下所有文件和子目录
   风险: 该目录不只有 thumbcache_*.db，还可能包含 Explorer 启动日志等
   修复: 限定为 thumbcache_*.db + thumbcache_idx.db

2. protectRecent 不穿透子目录 (第508行)
   现状: File.GetLastWriteTime(entry) 只检查顶级条目的修改时间
   风险: 2年前创建的目录内含今天修改的文件，保护完全失效，整个目录被删
   修复: 删除目录前递归检查内部是否有24h内修改的文件


== P1 中等问题 ==

3. EmptyRecycleBin() 永远返回成功 (第547行)
   现状: return hr == 0 ? 0 : 0; 两个分支都返回 0
   风险: 操作失败也报成功，用户误以为已清空
   修复: 返回真实错误码

4. 系统目录无管理员权限静默失败
   路径: C:\Windows\Temp, C:\Windows\SoftwareDistribution\Download
   现状: 权限不足时 catch { continue/skipped } 直接跳过
   风险: 用户看到"清理完成"但实际未删，造成误导
   修复: 扫描阶段预检权限，UI 标记"需要管理员权限"

5. 异常处理过于宽泛
   第381/391/501/525/550行使用裸 catch {}
   风险: PathTooLongException、OutOfMemoryException 等被静默吞掉
   修复: 仅捕获 IOException/UnauthorizedAccessException
