# 启动动画优化方向（2026-08-19）

> 状态：**方向规划稿，待 Four 确认**——确认后才动 `MainWindow.xaml.cs`。
> 执行完毕后按文档治理移入 `docs/待删除/`，关键结论记入当日 changelog。

## 背景与约束

当前开屏为黑遮罩两段式入场（`MainWindow.xaml.cs` OnWindowLoaded，204–256 行）：
文字弹入 1.3s → 图标滑入+文字让位 1.0s → 停留 0.5s → 淡出 0.5s，全程 3.3s。

**硬性约束（Four 2026-08-19 确认）：总时长不动。**
3.3s 不是审美选择，是功能需求——WPF 启动初期有一段时间无法绘制任何内容
（DWM 黑缓存帧期），黑遮罩必须盖住这段窗口期。时序骨架（1.3 / 1.0 / 0.5 / 0.5）保留，
本次只改"质感"，不改"节奏"。

## 改动点

### ① 缓动曲线统一（已确认）

- 品牌阶段的位移曲线（文字弹入、图标滑入、文字让位）从 `CubicEase EaseOut`
  换为 `KeySpline(0.16,1 → 0.3,1)`——即 8 月 10 日切回动画确立的 emphasized 曲线，
  起步更干脆、收尾更长柔，与全 app 设计语言统一。
- 文字淡入保留 `EaseIn`（2026-08-11 实测结论：首帧跳帧期 EaseOut 淡入不可见，不动）。
- 图标淡入默认保留 `EaseIn`（到位才透出的含蓄感；加了模糊聚焦后层次已够丰富）。
  留作调参项，实机看效果再定。

### ② 模糊渐变（Four 指定新增）

两处"从虚焦到聚焦"，均用 `BlurEffect.Radius` 动画（TaskbarMediaPopupWindow 已有同款先例）：

- **品牌元素聚焦入场**：
  - 阶段 1：文字 `Radius 6→0`，与弹入同步（1300ms）——文字从模糊中浮起、落定即清晰；
  - 阶段 2：图标 `Radius 5→0`，与滑入同步——图标从文字背后滑出时由虚转实。
- **内容揭示聚焦**：遮罩淡出时，主内容根元素 `Radius 6→0`（约 650ms），
  黑幕揭开的同时界面从模糊中"对上焦"。

**完成后必须将 Effect 置 null**（动画 Completed 回调），避免常驻离屏渲染开销与文字发虚。
半径控制在 ≤6px、时长 ≤700ms，低端 iGPU 掉帧风险可控；若实测掉帧，先降半径再降时长。

### ③ 遮罩淡出 × 内容入场编排（已确认）

现状：遮罩淡出期间底下的主界面完全静止，淡出结束 = 硬切到静态界面。
改为"幕布升起时舞台已在运动"：

- OnWindowLoaded 时（首帧前、遮罩仍纯黑）先把 NavPane / Content 置为入场起点
  （复用 SetReturnStartState 的设值模式，但**不碰 `_wasBackground`**，
  避免 Activated 误触发 PlayReturnAnimations 重播）；
- 遮罩淡出开始后约 +120ms，内容入场开播（左栏 X 滑入 500ms emphasized、
  右栏 Y 滑入 540ms +60ms 微错峰、淡入 QuadraticEase EaseOut）——
  动作前段隔着半透黑幕隐约可见，后段清晰呈现，形成"浮出"感；
- 与 ② 的内容模糊对焦同步进行。
- 实现上抽出共用编排方法（PlayReturnAnimations 与冷启动入场同源），
  全部偏移量走 BeginTime，一条时间轴驱动，不加定时器。

## 目标时间轴（总时长仍 3.3s）

| 时间 | 品牌层 | 内容层 |
|---|---|---|
| 0–1300ms | 文字 Y40→0（emphasized）+ 淡入 EaseIn + **模糊 6→0** | 静止于起点（不可见，遮罩下） |
| 1300–2300ms | 图标滑入+文字让位（emphasized）+ 图标淡入 EaseIn + **模糊 5→0** | 同上 |
| 2300–2800ms | 停留 | 同上 |
| 2800–3300ms | 遮罩淡出 500ms（CubicEase EaseOut，保持） | +120ms 起：左右栏滑入 + 淡入 + **模糊 6→0**（650ms） |
| 结束后 | StartupMask Collapsed | BlurEffect 置 null |

## 新增调参常量（集中调参区，与现有 Return* 常量同风格）

```
EntranceTitleBlurRadius = 6     // 文字聚焦起点半径
EntranceIconBlurRadius  = 5     // 图标聚焦起点半径
ContentBlurRadius       = 6     // 内容揭示聚焦起点半径
ContentBlurMs           = 650   // 内容对焦时长
ContentEntranceDelayMs  = 120   // 内容入场相对遮罩淡出的延迟
```

## 风险与验证

1. **BlurEffect 性能**：大面积模糊动画在低端 GPU 可能掉帧 → 实机目测 + 录屏逐帧验证；
   掉帧则先降半径（6→4）再降时长。
2. **模糊动画与首帧跳帧**：blur 半径跳帧无感（不像 opacity 的 EaseOut 问题），无需特殊对策。
3. **静默启动路径**：首次托盘唤起才触发 Loaded，同走本路径，需单独验证一次。
4. **回退**：改动集中于 `MainWindow.xaml.cs` 单文件（XAML 仅给 MaskTitle/MaskIcon/内容根
   各挂一个 BlurEffect 实例），git checkout 即整体回退。

## 明确不做

- 不缩短/不重排 1.3 / 1.0 / 0.5 / 0.5 的时序骨架（黑屏期遮盖是功能需求）；
- 不动遮罩淡出的 500ms 与 CubicEase EaseOut；
- 不给文字加缩放（模糊聚焦已提供"浮起"感，再加缩放会糊上叠糊，视觉噪声）。
