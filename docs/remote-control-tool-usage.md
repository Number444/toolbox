# RemoteControlTool 使用说明与冒烟测试清单

> 对应设计文档：docs/REMOTE_CONTROL_TOOL_DESIGN.md（实现 2026-08-07，里程碑 M1-M4 完成，实机冒烟待执行）。

## 一、使用说明

### 1. 启动服务

1. 打开 Toolbox → 左侧导航「⚙️ 系统维护」→「🛰️ 远程控制」
2. 端口默认 `8090`（冲突时更换；实际端口以面板显示为准）
3. Token 留空 = 启动时自动生成随机 Token（**仅存内存，不落盘**）；也可手动指定（仅当前会话有效）
4. 点「▶️ 启动服务」——状态灯变绿「● 运行中」，面板显示访问地址与当前 Token

### 2. 控制端访问（手机/电脑浏览器）

1. 设备需与电脑处于**同一局域网**（同一 Wi-Fi/交换机）
2. 浏览器打开面板显示的访问地址，如 `http://192.168.1.100:8090/`
3. 首次访问会弹 Token 输入遮罩——输入面板上显示的当前 Token（可用「📋 复制 Token」按钮）
4. 登录后会话保持 8 小时（浏览器 Cookie）

### 3. 防火墙放行

首次启动服务时 Windows 防火墙会弹窗，选择**允许专用网络**（信任局域网）即可。
若弹窗被忽略：设置 → Windows 安全中心 → 防火墙和网络保护 → 允许应用通过防火墙 → 允许 Toolbox 专用网络。

### 4. 指令说明

| 指令 | 是否需要确认 | 说明 |
|------|:---:|------|
| 锁屏 / 睡眠 / 关显示器 / 重启资源管理器 | 否 | 一键执行 |
| 定时关机 / 立即关机 / 重启电脑 | **是**（页面确认 + 服务端 confirm 校验） | 关机重启前页面弹确认框 |
| 取消关机 | 否 | 取消已排程的关机 |

### 5. 停止服务

- 面板「⏹ 停止服务」按钮
- 或切换到其他工具 / 关闭 Toolbox（工具页 Unloaded 自动停止，无后台残留监听）

### 6. 常见问题排查

| 现象 | 排查 |
|------|------|
| 手机/其他电脑访问不了 | ① 防火墙未放行（见第 3 节）② 不在同一局域网 ③ 路由器开了 **AP 隔离**（管理后台关闭） |
| 面板显示"未检测到局域网 IP" | 检查网卡是否启用、是否连上路由器（有网关） |
| 启动报"端口被占用" | 换一个端口（如 8091） |
| 忘记 Token | 服务重启即重新生成，面板重新查看/复制 |
| 访问提示"无法连接" | 电脑是否睡眠/关机、服务是否已停止 |

## 二、Windows 实机冒烟测试清单（M5 待执行）

> 目标：验证主方案（TcpHttpServer）在真实网络环境可用；不通过 → 按设计文档 13.2 切换备方案 HttpListenerServer。

### 1. 基础流程

- [ ] Toolbox 启动 → 打开远程控制工具页 → 面板正常显示（无异常）
- [ ] 点「▶️ 启动服务」→ 状态灯变绿、显示访问地址与 Token
- [ ] 本机浏览器打开 `http://127.0.0.1:{port}/` → 控制页正常渲染（深色主题）

### 2. 认证

- [ ] 输入错误 Token → 提示"invalid token"，不进入
- [ ] 连续输错 5 次 → 提示锁定 30s（即使正确 Token 也拒绝）
- [ ] 输入正确 Token → 进入控制页，状态仪表出现数据（3s 自动刷新）
- [ ] 刷新浏览器页面 → 会话保持（Cookie 生效，无需重新输入）

### 3. 指令（真机，注意安全——确认弹窗可取消）

- [ ] 锁屏 / 关显示器 / 睡眠 / 重启资源管理器 → 各执行一次（重启资源管理器后桌面图标恢复）
- [ ] 「定时关机 60 秒」→ 确认 → 系统提示"将在 1 分钟内关闭"→ **立即「取消关机」** 验证可取消
- [ ] 「取消关机」→ 提示"系统没有未完成的关机操作"→ 属于预期（shutdown /a 正常输出）
- [ ] 危险指令不带确认 → 服务端拒绝（可临时用 curl 验证：
      `curl -X POST http://127.0.0.1:8090/api/command -H "Content-Type: application/json" -H "X-Requested-With: RemoteControl" -H "Cookie: rc_session=xxx" -d '{"command":"restart"}'` → 应返回 confirm 错误）

### 4. 状态监控

- [ ] CPU/内存/磁盘进度条数值合理，3s 自动刷新
- [ ] 拔掉网线 → 控制页显示"无法连接"→ 插回网线自动恢复（不用重开页面）
- [ ] 无公网环境（离线）下 network 详情公网 IP 显示空，不报错

### 5. 多设备/并发

- [ ] 手机浏览器（同一 Wi-Fi）访问控制页正常
- [ ] 两台设备同时打开控制页并轮询状态 → 无卡顿、无报错
- [ ] 快速连续点击「锁屏」多次 → 服务不崩溃，操作日志逐条记录

### 6. 畸形请求/健壮性

- [ ] 浏览器地址栏访问 `http://127.0.0.1:{port}/api/status` 直接回车（无 Cookie）→ 401 JSON
- [ ] 访问不存在的路径 `/api/nope` → 404 JSON
- [ ] 用 curl 发送畸形请求（如 `curl http://127.0.0.1:{port}/ -d "garbage"`）→ 服务不崩溃，后续正常请求仍可访问
- [ ] 连续快速刷新控制页 50 次 → 无连接泄漏、无挂起

### 7. 生命周期

- [ ] 点「⏹ 停止服务」→ 状态灯变红，控制页无法再访问（连接失败）
- [ ] 服务运行中切换到其他工具再切回来 → 服务已自动停止（Unloaded 生效）、面板状态与实际一致（"已停止"）
- [ ] 重复点启动/停止 5 次 → 无异常（幂等）
- [ ] 服务运行中关闭 Toolbox → 端口不再监听（`netstat -ano | findstr 8090` 无结果）

### 8. 决策回填

- [ ] 以上全部通过 → 在 REMOTE_CONTROL_TOOL_DESIGN.md 13.4 回填"主方案确认"；任何一项不通过 → 记录现象并评估切换 HttpListenerServer（13.2 条件）
